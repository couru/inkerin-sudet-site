# Inkerin Sudet — тёмный графитовый макет вышивки

Комплект для фронтальной вышивки на чёрной бейсболке.

## Содержимое

- `inkerin-sudet-graphite-dark.eps` — основной производственный векторный макет;
- `inkerin-sudet-graphite-dark.svg` — редактируемая векторная копия;
- `inkerin-sudet-graphite-dark.png` — прозрачный эталон цветоделения;
- `inkerin-sudet-graphite-dark-black-cap-preview.png` — превью на чёрной ткани.

## Параметры

- рабочее поле: 100 × 100 мм; минимальная рекомендуемая высота — 85 мм;
- цвета нитей: #5F5F61, #424244, #232426, #534737, #102334, #451E1D;
- чёрный цвет обеспечивает ткань кепки и не зашивается;
- SVG и EPS содержат только кривые, без шрифтов и встроенного растра;
- перед производством требуется оцифровка в DST/PES под конкретную машину и пробный отшив.
