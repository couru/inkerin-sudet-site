# Inkerin Sudet — графитовый макет вышивки

Комплект для фронтальной вышивки на чёрной бейсболке.

## Содержимое

- `inkerin-sudet-graphite.eps` — основной производственный векторный макет;
- `inkerin-sudet-graphite.svg` — редактируемая векторная копия;
- `inkerin-sudet-graphite.png` — прозрачный эталон цветоделения;
- `inkerin-sudet-graphite-black-cap-preview.png` — превью на чёрной ткани.

## Параметры

- рабочее поле: 100 × 100 мм; минимальная рекомендуемая высота — 85 мм;
- цвета нитей: #515457, #3A3D40, #222426, #74684E, #2B4D62, #7B302F;
- чёрный цвет обеспечивает ткань кепки и не зашивается;
- SVG и EPS содержат только кривые, без шрифтов и встроенного растра;
- перед производством требуется оцифровка в DST/PES под конкретную машину и пробный отшив.
